03 — On your phone

Same tools, plain conversation.

A preview of what a Claude conversation with these tools looks like on mobile.
Personal Expense Tracker
I spent 25 on groceries today for milk and bread, add it to my expenses
→ add_expense({ amount: 25, category: "groceries", date: "2026-08-16" })
Done — I added your $25 groceries expense for milk and bread.
how much did I spend this month?
→ get_spending_summary({ month: "2026-08" })
You spent $240 this month across 8 expenses — groceries was the biggest category.

05 — Run it yourself

        
Local by design.

      

      
No cloud, no login. Clone, install, and it's yours.

    


    

      

      

# clone the project

$ git clone https://github.com/MohammadYousef-001/Personal-Expenses-Tracker.git

$ cd Personal-Expenses-Tracker

$ npm install



# run the MCP server locally over stdio

$ npm run dev



# or open MCP Inspector to test tools by hand

$ npm run inspect
      

    

    
This showcase page is fully static — clone this repo and open index.html directly, or serve it with npx serve .. It doesn't call the live server; the tool card above shows real fixture data captured during testing.
